# Documentation assets

[`docs/assets/picker.png`](docs/assets/picker.png) is a native Rofi capture
generated by [`scripts/render-preview`](scripts/render-preview). It uses the
production frame renderer with synthetic hosts, environment labels and window
titles. It contains no live inventory, conversation content or private paths.

The script creates a private Xvfb display, a private Rofi PID file and an inert
callback. The preview theme is embedded in the script; normal Agent Plus uses
the user's Rofi theme. ImageMagick captures and trims the rendered window.
DejaVu Sans Mono supplies the text. This is a documentation illustration,
rather than native provider-entry or human-input acceptance evidence.

Regenerate it with:

```sh
python -B scripts/render-preview --output docs/assets/picker.png
```

The generated image and project-owned theme are covered by the repository's
[MIT license](LICENSE). Rofi and the installed font are external rendering
dependencies, not bundled assets.

The previous provider SVGs were unused by the direct picker and are no longer
packaged. Their source/license attribution remains available at
`git show 6f724e099c498930f3592bbaef9e1f0f3d2289f6:ASSETS.md`.
